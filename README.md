# Wine_Quality_predidiction
Wine Quality Prediction Using Machine Learning

1. Internship Details

- Organization: Oasis Infobyte
- Internship: Data Science Internship
- Task: Wine Quality Prediction

2. Project Objective

The main objective of this project is to predict wine quality using Machine Learning algorithms based on the physicochemical properties of wine.

3. Dataset Description

The dataset contains 1,143 rows and 13 columns.

It includes the following features:

- Fixed Acidity
- Volatile Acidity
- Citric Acid
- Residual Sugar
- Chlorides
- Free Sulfur Dioxide
- Total Sulfur Dioxide
- Density
- pH
- Sulphates
- Alcohol
- Quality

Target Variable: Quality

4. Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab / Jupyter Notebook

5. Machine Learning Algorithms

- Linear Regression
- Random Forest Regression

6. Project Workflow

1. Import required libraries.
2. Load the Wine Quality dataset.
3. Perform data cleaning and preprocessing.
4. Perform Exploratory Data Analysis (EDA).
5. Visualize the dataset using graphs.
6. Split the dataset into training and testing data.
7. Train Machine Learning models.
8. Evaluate model performance.
9. Predict wine quality.

7. Model Evaluation

The models are evaluated using:

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score

8. Conclusion

This project demonstrates how Machine Learning techniques can be used to predict wine quality based on its physicochemical properties. It helps understand data preprocessing, visualization, model training, and prediction.
